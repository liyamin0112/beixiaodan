# 背小单 · 背单词微信小程序

一个可以直接跑起来的背单词小程序：**内置 6 本词库（1147 词，含五年级上册教材词表 + 常用表达）+ 自己导入词库 + 记忆曲线复习 + 选择题/拼写测试 + 打卡与学习统计 + 多用户账号**。
后端是纯 Node 内置模块实现的，**不需要 npm install，没有数据库**，所有数据存在一个 JSON 文件里。

├── start.sh              ← 双击/命令行运行这个，服务就起来了

## 三步跑起来

**1. 启动后端**

```bash
cd 背小单
./start.sh
```

看到 `背小单 · 背单词服务已启动` 就成功了。换端口：`PORT=8899 ./start.sh`。

**2. 打开小程序**

打开「微信开发者工具」→ 导入项目 → 目录选 `背小单/miniprogram` → AppID 点「测试号」（或填自己的）。

**3. 关掉域名校验（本地调试必做）**

开发者工具右上角「详情」→「本地设置」→ 勾选 **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**。

然后编译即可使用：小程序会用 `wx.login` 静默登录，后端没配 AppID 时自动落到演示账号，本地能直接体验完整流程。

## 手机上看效果

手机和电脑连同一个 WiFi，在小程序里进入 **我的 → 服务器地址**，把地址改成 start.sh 打印的那个局域网地址（例如 `http://192.168.1.10:8787`），保存后重新编译/预览即可。
也可以改 `miniprogram/utils/config.js` 里的 `DEFAULT_BASE_URL` 一劳永逸。

## 背单词逻辑（记忆曲线）

背卡片时四个按钮对应复习间隔：

- **不认识**：10 分钟后回炉，本次背诵里会再出现
- **有点忘**：间隔按 1.2 倍缓慢增长，难度系数下调
- **记得**：间隔 × 难度系数（初始 2.5），1 天 → 2 天 → 5 天 → 12 天…
- **很熟**：间隔 × 1.3 倍，难度系数上调

间隔到 30 天以上标记为「已掌握」，每半年回访一次。到期的词会自动排进当天的任务，每天任务量 = 「每日目标」，其中新词数量 = 「每日新词」。

## 加自己的词库

小程序里：**词库 → 新建词库 → 批量导入**，粘贴 CSV（一行一个，逗号分隔；带表头更稳）。表头中英文都认：

```
word,meaning,phonetic,pos,example,example_cn
reservation,预订；预约,/rezərˈveɪʃn/,n.,I have a reservation for two nights.,我有一个两晚的预订。
```
中文表头 `单词,释义,音标,词性,例句,例句翻译` 同样可以。没有音标、例句也能导入。

参考文件：`server/data/导入示例.csv`。内置词库是只读的，想改词就导进自己的词库。
想直接增加一本内置词库：把 JSON 放进 `server/data/wordbooks/`（照 `hotel.json` 的格式），重启服务即自动载入。

## 备份 / 迁移数据

所有用户数据都在 `server/data/db.json`（写入前会先落 `db.json.tmp` 再原子替换）。
备份 = 拷走这个文件；恢复 = 放回原位重启。删掉它 = 一切回到初始状态（内置词库不受影响）。

## 正式上线到微信（需要时再做）

1. 注册小程序拿到 **AppID**，填进 `miniprogram/project.config.json`。
2. 准备一个 **已备案的 HTTPS 域名**（微信小程序不允许 http 和 IP），把 `server/` 部署上去，用 nginx 反代到 8787 端口。
3. 小程序后台「开发管理 → 开发设置 → 服务器域名」里把该域名加进 **request 合法域名**。
4. 环境变量里配置 `WX_APPID`、`WX_SECRET`，`/api/auth/wx-login` 就会真正用微信身份建账号（现在没配时自动走演示账号）。
5. 发音用的是有道公开词典音频，正式环境建议在 `miniprogram/utils/speak.js` 换成自有域名或去掉该功能，并把用到的域名加进 **downloadFile 合法域名**。
6. 后端是单机 JSON 存储，适合小团队/家庭/店内使用；如果多人同时高频写数据，再考虑换成数据库。
